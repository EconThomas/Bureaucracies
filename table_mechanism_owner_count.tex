The instruments and the reduced form are the same in every row, so the measures rescale one relationship. All IV specifications include reservation fixed effects, lease-signing year fixed effects, lease term, fee-simple share, and log tract acreage. Standard errors cluster by reservation. Wild-cluster bootstrap $p$-values use WRE-N with 99,999 replications. Over-identification $p$-values are Sargan tests.
